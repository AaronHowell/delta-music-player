Design ideas (no code copied; both projects are GPL-3.0, which is why no code
is copied) were studied from:

  MeowField_AutoPiano — https://github.com/Tsundeer/MeowField_AutoPiano
      absolute-timeline scheduling with origin shifting on pause, two-phase
      wait (sleep + busy-wait), key depth reference counting, minimum key
      hold, same-instant up-before-down ordering, 1 ms inter-event gaps in a
      batch, release-all-keys on every exit path.

  AutoMidiPlayer — https://github.com/Jed556/AutoMidiPlayer
      instrument profile modelling, octave folding with nearest-playable
      snapping for scale gaps, tempo-map preservation when filtering tracks,
      melody track auto-selection heuristics.
